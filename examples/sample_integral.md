# 示例会话 · 积分急救 → 抽奖 → 券叠加闭环

> 以下为「旗舰情景」的真实调用演示。账号数据来自 2026-10-17 实测（已脱敏展示）。

## 用户

> 我积分是不是快过期了？帮我看看怎么花最划算。

## Step 1 · 读取积分账户（query-my-account，只读）

```
可用积分: 43.2
累计积分: 252.7
本月将过期: 13.5   ← 关键钩子
下月将过期: 0
```

## Step 2 · 本地决策引擎（scripts/integral_rescue.py）

```
python scripts/integral_rescue.py --available 43.2 --expire-now 13.5 --draw-point 24 \
    --prizes "积分霸王餐,麦辣鸡腿汉堡5折券,下单立减3元券,..."

=== 麦麦智选 · 积分急救诊断 ===
[诊断] 你本月有 13.5 积分将过期，且可用积分足够抽一次（24 分），
       用将过期积分抽奖最划算：不花『干净积分』还能搏优惠券。
[建议] 优先执行 → lottery
```

## Step 3 · 展示抽奖消耗与奖池（query-lottery-info，只读）

```
活动：周六麦金喜抽奖（进行中）
消耗：24 积分/次（本次将消耗 24 积分）
奖池（节选）：积分霸王餐、麦金卡7天、麦辣鸡腿汉堡5折券、
            下单立减3元券、圆筒冰淇淋4折券、28会员积分 …
剩余：可用 43.2 积分，可参与
```

## Step 4 · 用户确认 → 抽奖（draw-lottery）

> 用户：行，帮我抽一次。

（调用 `draw-lottery`，严格在确认后执行；严禁自动抽/试抽）

```
中奖：麦辣鸡腿汉堡5折券
```

## Step 5 · 中奖券回结合层 × 增肌午餐（calculate-price 实算）

- 饮食引擎筛出增肌午餐：板烧鸡腿堡 + 中薯条 + 无糖可乐（蛋白 27g）
- 叠加「麦辣鸡腿汉堡5折券」：若将板烧替换为麦辣鸡腿堡（原价 ¥24.5，5 折 ≈ ¥12.25）
- `calculate-price` 实算组合到手价，输出「省 ¥X」方案卡

## 输出方案卡

```
🍔 麦麦智选 · 积分急救方案
  · 你本月 13.5 积分将过期 → 已用抽奖消耗 24 分（含将过期部分）
  · 中奖：麦辣鸡腿汉堡5折券
  · 搭配增肌午餐，到手价 ¥XX.X（calculate-price 实算）
  · 省 ¥X，蛋白达标
* 仅供参考，非专业建议；以官方实时为准
```

---

## 合规要点

- `query-lottery-info` 必须**先**展示 `drawDecision.nextConsumption` 与剩余；
- 用户明确确认后才能调用 `draw-lottery`；
- 严禁根据 `availableTimes` 自行推断能否抽、严禁试抽/自动抽/连续抽。
