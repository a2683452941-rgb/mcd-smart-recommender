# 营养与搭配规则参考

本文件供 `SKILL.md` 的饮食推荐引擎引用，定义筛选阈值、场景映射与组合搭配价规则。
所有数值单位：能量 kcal、蛋白/脂肪/碳水/钠 mg（与 `list-nutrition-foods` 返回一致）。

## 1. 目标阈值

| 目标 | 蛋白 | 热量 | 钠 | 说明 |
|------|------|------|----|------|
| `fat_loss` 减脂 | ≥ 20g | ≤ 400 | ≤ 700 | 高蛋白低热量，控制钠以防水肿 |
| `muscle_gain` 增肌 | ≥ 25g | ≥ 400 | 适中 | 蛋白优先，热量充足支持合成 |
| `low_sugar` 控糖 | — | 常规 | 适中 | 规避高糖甜品/雪冰，优先无糖饮 |
| `balanced` 均衡 | 10-30g | 300-600 | ≤ 800 | 三大营养素均衡，钠适中 |
| `children` 儿童家庭 | 8-22g | 150-350 | ≤ 500 | 低钠、小份、温和，规避带骨/辣 |
| `office` 上班族快手 | 12-30g | 300-500 | ≤ 900 | 性价比、快速、饱腹 |

## 2. 场景映射

| 场景 | 优先品类 | 示例 |
|------|----------|------|
| 早餐 | 麦满分、粥、豆浆、鲜萃咖啡 | 猪柳蛋麦满分 + 优品豆浆 |
| 午餐/正餐 | 汉堡 + 薯条/小食 + 饮料 | 板烧鸡腿堡 + 中薯条 + 无糖可乐 |
| 下午茶 | 麦旋风、派、玉米杯、麦乐鸡 | 奥利奥麦旋风 + 麦乐鸡(分享) |
| 夜宵 | 主食类、粥 | 汉堡包 + 锡兰红茶 |
| 健身后 | 高蛋白 + 快速碳水 | 麦辣鸡腿汉堡 + 中杯可乐 |

## 3. 组合搭配价规则（来自 `query-meals` 的企业团餐/搭配参考）

- 20 元以下：小食
- 20-30 元：汉堡 + 小食 或 汉堡 + 饮料
- 30-40 元：汉堡 + 薯条/小食 + 饮料
- 40-50 元：汉堡 + 薯条 + 小食 + 饮料
- 50 元以上：丰富组合，优先不重复小食

## 4. 忌口处理

- 过敏源：依据营养/餐品名剔除（如含「虾」「鱼」「坚果」「蛋」「奶」等关键词）。
- 宗教/口味：猪肉相关（猪柳、火腿扒、香肠）→ 替换为鸡/鱼/牛肉类。
- 不要辣：剔除「麦辣」「辣」关键词餐品。

## 5. 评分函数（供 `scripts/recommend.py` 使用）

对每个候选餐品计算 score：
- 蛋白命中目标：+40；接近目标：+20
- 热量在目标区间：+30；偏离：线性扣分
- 钠 ≤ 阈值：+15；超出：扣分
- 场景匹配：+15
- 忌口命中：直接排除

最终按 score 降序，输出 Top N 与组合建议。

## 6. 儿童/家庭 与 上班族快手 专项规则

### 儿童/家庭（children）
- 安全与口味优先：自动排除含「辣 / 带骨 / 麦辣 / 椒」等关键词餐品（带骨里脊等有呛噎风险，辣味不适合儿童）。
- 营养：蛋白 8-22g（支持生长）、热量 150-350kcal（小份）、钠 ≤ 500mg（越低越好）。
- 优选：儿童鱼排堡、麦乐鸡（去骨）、玉米杯小杯、苹果片、小薯条、纯牛奶、优品豆浆、汉堡包、麦香鱼、粥、麦满分。
- 组合建议：主餐(鱼排堡/麦香鱼) + 小份主食(小薯条/玉米杯) + 奶/豆浆。

### 上班族快手（office）
- 决策效率与性价比优先：快速可得、饱腹、价格友好（偏好 20-40 元档：汉堡+小食/饮料）。
- 营养：蛋白 12-30g（饱腹）、热量 300-500kcal、钠 ≤ 900mg。
- 优选：麦满分/粥（早餐）、板烧鸡腿堡、吉士汉堡、汉堡包、中薯条、鲜萃咖啡、优品豆浆。
- 组合建议：早餐 → 麦满分 + 豆浆 + 鲜萃咖啡；午餐 → 汉堡 + 中薯条 + 无糖饮。

## 7. 情景叠加层（时间 / 情绪 / 出行 / 随机）

这些不是"目标"，而是叠加在目标之上的**上下文约束**，由 `now-time-info` / 用户表述 / 目的地 触发。

### 深夜宵夜（night，now-time-info 小时 ≥ 21）
- 主推热食：粥、汉堡、热红茶 / 热咖啡；**规避冰饮**（无糖可乐、雪碧、麦旋酷）与大份甜品（麦旋风、新地）。
- 偏向低负担组合（合计 ≤ 600kcal），避免深夜高钠重口。
- 实现：`scripts/recommend.py` 的 `SCENE_MAP["night"]` 已含 汉堡/粥/红茶/咖啡。

### 情绪治愈 / 提神（mood）
- **治愈系**（累 / emo / 犒劳 / 开心）：轻甜慰藉优先——麦旋风、新地、派、玉米杯、麦乐鸡（分享）；允许适度"放纵"，但仍标注热量。
- **提神系**（困 / 加班 / 早起 / 考试）：美式 / 鲜萃咖啡、无糖可乐、麦满分高蛋白早餐。
- 触发词：累、困、加班、犒劳、开心、学不进去、早起 等。

### 出差旅游落地（travel，用户告知目的地 或 now-time-info 非常驻地）
- 流程见 `references/creative_scenarios.md` ③：`query-nearby-stores` 取最近门店 → `query-meals` 当期菜单 → `campaign-calendar` 当期活动（如 9.9 元早餐两件套、龙焰鸡腿堡新品）→ 饮食引擎筛餐 → `calculate-price`。
- 可结合"当地限定/当期新品"做话题钩子。

### 盲盒随机（blind_box，`scripts/blind_box.py`）
- 给约束但不想自己选时：复用 `recommend.py` 的 `NUTRITION`/`recommend()`，按目标筛分后在 Top 候选里**分桶随机**（主/副/饮各取其一），保证"随机但不离谱"。
- 用法：`python scripts/blind_box.py --goal muscle_gain --scene lunch --avoid 猪,辣 [--seed N]`。
